# @upi-spend-tracker/mobile-ui

Shared mobile design-system package for the Expo client.

## Exports

- `designTokens`
- `lightTheme`
- `darkTheme`
- `AppShell`
- `Button`
- `Card`
- `ListItem`
- `BottomSheet`
- `TextField`
- `Chip`
- `EmptyState`
- `SectionHeader`
- `KPIBlock`

## Notes

- Tokens cover spacing, typography, radius, elevation, semantic colors, icon sizes, motion, and minimum touch targets.
- Components support both light and dark themes through `AppShell` or `MobileUiThemeProvider`.
- The client exposes a showcase screen from Home via `View UI showcase` to demonstrate every primitive in one place.
